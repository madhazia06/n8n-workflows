# Restaurant AI Voice Reservation System

An AI-powered restaurant reservation automation built with **n8n**, **Groq**, **Google Calendar**, and **Google Sheets**.

The project demonstrates how an AI voice or conversational interface can connect with n8n webhooks to check reservation availability, create bookings, and maintain reservation records automatically.

## Features

* 🤖 AI-powered reservation handling
* 📅 Real-time availability checking with Google Calendar
* ✅ Automatic reservation creation
* 📝 Reservation logging in Google Sheets
* 🔗 Webhook-based integration for voice agents and external applications
* ⚡ Automated using n8n
* 🧠 Natural-language processing powered by Groq

## Workflow Architecture

The project contains two n8n workflows.

### 1. Reservation Calendar Agent

`workflow-reservation-calendar-agent.json`

Handles reservation availability and booking through an AI agent.

```text
Check Reservation Webhook
        ↓
     AI Agent
      ├── Groq LLM
      └── Google Calendar
              ↓
      Check Availability
              ↓
      Webhook Response
```

It also provides a booking flow:

```text
Book Reservation Webhook
        ↓
     AI Agent
      ├── Groq LLM
      └── Create Google Calendar Event
              ↓
      Webhook Response
```

The agent can:

* Check existing reservations
* Determine availability for a requested date and time
* Create new reservations
* Create one-hour calendar appointments
* Return responses through the webhook

### 2. Reservation Record Handler

`workflow-reservation-record-handler.json`

Stores reservation information received through a webhook.

```text
Reservation Webhook
        ↓
Google Sheets
        ↓
Append Reservation
        ↓
Webhook Response
```

The workflow records:

* Customer name
* Reservation date
* Reservation time
* Number of guests

Before importing the workflows, you will need:

* A running n8n instance
* Groq API credentials
* Google Calendar OAuth credentials
* Google Sheets OAuth credentials
* A Google Calendar for reservations
* A Google Sheet for reservation records

## Setup

### 1. Import the Workflows

Import both JSON files into n8n:

```text
workflows/reservation-calendar-agent.json
workflows/reservation-record-handler.json
```

### 2. Configure Groq

Create a Groq credential inside n8n and connect it to the Groq Chat Model nodes.

The workflow currently uses:

```text
llama-3.3-70b-versatile
```

You can replace this with another compatible model if required.

### 3. Configure Google Calendar

Connect your Google Calendar account to the calendar nodes.

The calendar agent requires permission to:

* Read existing events
* Create new events

Select the calendar that should be used for restaurant reservations.

### 4. Configure Google Sheets

Create a spreadsheet containing these columns:

```text
Name | Date | Time | Number_Of_People
```

Connect the Google Sheets node to your spreadsheet and map the corresponding fields.

### 5. Configure Webhooks

The Calendar Agent exposes endpoints for:

```text
POST /check_reservation
POST /book_reservation
```

The Record Handler exposes a separate endpoint for receiving reservation information.

Use the production webhook URLs generated by your own n8n instance when integrating with a voice agent or another application.

## Example Reservation Payload

A booking request can contain:

```json
{
  "name": "John Doe",
  "date": "2026-08-15",
  "time": "19:00",
  "number_of_people": 4
}
```

The workflow can then create the reservation and/or store the information depending on which endpoint is called.
